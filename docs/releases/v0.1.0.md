# SLCL v0.1.0

首个公开版本。

SLCL（SLATT Client）是一个基于 Electron + React + TypeScript 的 Minecraft Java 版启动器，面向 Windows 桌面。

---

## 下载

| 文件 | 说明 |
|---|---|
| `SLCL Setup 0.1.0.exe` | Windows 安装程序（110 MB） |
| `SHA256SUMS.txt` | 校验值 |

**系统要求**：Windows 10 / 11（64 位）

> 首次运行时 Windows SmartScreen 可能提示「已保护你的电脑」。这是因为本项目未购买代码签名证书，属于正常现象。
> 点击 **更多信息 → 仍要运行** 即可；你也可以先用 `SHA256SUMS.txt` 校验文件完整性。

## 功能

### 账户

- 离线登录 —— 单机即开即玩
- Microsoft 正版登录 —— 设备码流程，自动显示正版皮肤
- LittleSkin 外置登录 —— 自动注入 authlib-injector

### 版本管理

- 安装原版，或叠加 Fabric / Forge / NeoForge（含 1.12.2 legacy Forge）
- 支持多个游戏文件夹，自动扫描与切换
- 版本隔离：每个版本独立存档 / 模组 / 配置目录
- 像素风格版本图标，区分原版 / Forge / Fabric / 快照 / 远古版
- 版本排序、重命名、修复、删除、打开文件夹、查看截图
- 每个版本可单独设置内存与 Java

### 资源下载

- Modrinth 与 CurseForge 双源，可随时切换
- 模组、资源包、光影、数据包、整合包五类内容
- 按加载器 / 游戏版本过滤，分页浏览热门推荐
- 整合包一键安装：`.mrpack` 与 CurseForge `.zip` 均支持，自动创建对应游戏版本与加载器
- 已安装内容支持图标预览、启用 / 停用、删除
- **CurseForge 无需 API Key**（默认走国内镜像）

### Java

- 自动检测系统已安装的 Java
- 按版本实际要求匹配：1.12.2 → Java 8，1.18+ → 17，1.21+ → 21，26.x → 25
- Adoptium Temurin 一键安装任意主版本，支持取消与进度显示
- 支持手动导入任意 Java 路径

### 启动与诊断

- 主页直接选择启动版本，实时日志（默认折叠）
- 内存 / 分辨率 / 全屏 / 额外 JVM 参数可配置
- **崩溃自动诊断**，覆盖：缺少前置模组、模组版本不匹配、模组重复或冲突、Java 版本过低、
  内存不足、Mixin 注入失败、显卡驱动异常、游戏文件损坏、Java 路径失效等
- 诊断弹窗提供：**确认** / **查看输出**（打开真实游戏日志）/ **导出错误报告**
  （诊断结论 + 崩溃报告 + 完整日志，可直接发给开发者）

### 界面

- 无边框自定义标题栏
- 8 套配色 × 深浅双模式：翡翠绿、海洋蓝、日落橙、樱花粉、紫罗兰、青柠、朱红、靛蓝
- 自定义背景图与透明度
- 开屏动画、页面切换与弹窗动效

### 网络

- BMCLAPI 镜像加速 Mojang / Forge / Fabric / NeoForge 下载
- MCIM 镜像加速 Modrinth / CurseForge 元数据与文件
- 下载带停顿检测、大文件优先、字节级进度；镜像失败自动回退官方源

## 安装

1. 下载 `SLCL Setup 0.1.0.exe`
2. 双击运行，按向导完成安装
3. 安装位置可选；若只选盘符根目录（如 `D:\`），安装程序会自动装到 `D:\SLCL`，不会把文件散落到根目录
4. 卸载时可选择是否同时删除 `%APPDATA%\slcl` 中的配置缓存

## 已知限制

- 仅提供 Windows 构建；其他平台需自行从源码构建（见仓库 README）
- 未做代码签名，SmartScreen 会提示未知发布者
- 通过镜像下载**不计入模组作者收益**；若希望支持作者，可在「游戏设置」填写自己的 CurseForge API Key 走官方接口
- 镜像为第三方公益服务，稳定性不受本项目控制，失败时会自动回退官方源

## 数据位置

| 内容 | 位置 |
|---|---|
| 启动器配置 | `%APPDATA%\slcl\config.json` |
| 皮肤缓存 | `%APPDATA%\slcl\skins\` |
| SLCL 安装的 Java | `%APPDATA%\slcl\java\` |
| 默认游戏目录 | `%APPDATA%\.minecraft` |

Microsoft 访问令牌仅存于内存，不写入磁盘。
