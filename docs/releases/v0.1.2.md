# SLCL v0.1.2

这一版集中在三件事：**下载更可靠**、**找模组更方便**、**外观更可定制**。
另外补上了离线账户皮肤真正生效、以及下载完整性校验。

---

## 下载

| 文件 | 说明 |
|---|---|
| `SLCL Setup 0.1.2.exe` | Windows 安装程序（约 110 MB） |
| `SHA256SUMS.txt` | 校验值 |

**系统要求**：Windows 10 / 11（64 位）

> 首次运行时 Windows SmartScreen 可能提示「已保护你的电脑」。这是因为本项目未购买代码签名证书，属于正常现象。
> 点击 **更多信息 → 仍要运行** 即可；也可以先用 `SHA256SUMS.txt` 校验文件完整性。

## 更新内容

### 新增

- **中文名搜索模组**：输入「机械动力」「物品管理器」「钠」即可搜到 Create / JEI / Sodium
  （通过 MC百科 中文名译为英文后检索；模组卡片默认显示中文名，英文名作为灰字附注）
- **前置模组识别与一键安装**：安装页面直接列出所选版本需要的前置，
  可勾选「安装模组时一并安装」，也能对每个前置单独选择版本并安装
- **前置版本可自选**：每个前置提供版本下拉，显示版本号与发布日期，默认选中与游戏版本 + 加载器最匹配的一项
- **标题栏文字可自定义**：可替换为任意文字，留空即隐藏；文字颜色自动跟随明暗模式与主题
- **标题栏图标可单独开关**：与文字设置互不影响，收起/展开带过渡动画，并支持「减少动态效果」偏好
- **7 套新配色**，总计 15 套：新增明黄、森绿、碧青、蔚蓝、紫水晶、洋红、玫红，并按色相从红到紫重新排序

### 改进

- **离线账户皮肤真正生效**：启动时通过本地皮肤服务把选定皮肤提供给游戏，
  不再只是启动器内的预览（此前进入游戏仍是史蒂夫）
- **皮肤手臂粗细与皮肤一起保存**：经典（Steve）/ 纤细（Alex）不再丢失，团队皮肤库应用时与官网一致
- **安装筛选只列该资源支持的版本与加载器**：不再出现选了某个版本结果列表为空的情况；
  默认选中当前游戏版本，资源不支持时自动回退「全部版本」
- **「已安装」判定改用 modId**：同一模组装过任意版本都会识别为已安装，即使文件名不同（跨源安装、手动改名也认得出）
- **安装时自动替换同 modId 的旧文件**：不会再出现两个同 modId 的 jar 导致游戏无法启动
- **配色区分度提高**：最接近的一对颜色感知差异从 ΔE 10.1 提升到 26.0（深色）/ 17.6（浅色），浅色模式全部满足 WCAG AA 对比度
- **依赖解析更快**：按候选版本批量查询，JEI 这类上千个版本的项目也能在合理时间内解析出前置

### 修复

- **下载被截断却当成成功**：连接提前关闭时会留下不完整的 jar（实测有用户目录里留下 768 KB 的半个 Sodium），
  现在按 `Content-Length` 与实际字节数比对，并用 Modrinth 的 sha1 复核，不符则删除并报错
- **「前置已安装」却仍能再装一次**：切换前置版本后按钮又变回「安装」，导致装出两份同 modId 的模组
- **SLATT 团队账号角色显示错误**：技术部成员与超级管理员此前都显示为「团队成员」，
  现按官网权限组正确显示（超级管理员 / 主管 / 技术部成员 / 团队成员）
- **128× 皮肤被静默接受**：正版与离线都无法使用却不提示，现在会明确拒绝并说明原因；
  团队皮肤库中 128× 皮肤只允许下载到本地文件夹，并标注尺寸
- **非模组类别出现无效的 MC百科 链接**：资源包 / 光影 / 数据包 / 整合包在 MC百科 无对应条目，已移除该入口
- **资源下载页报错文案**：不再暴露 Electron 内部 IPC 通道名

## 安装

1. 下载 `SLCL Setup 0.1.2.exe`
2. 双击运行，按向导完成安装
3. 安装位置可选；若只选盘符根目录（如 `D:\`），安装程序会自动装到 `D:\SLCL`，不会把文件散落到根目录
4. 卸载时可选择是否同时删除 `%APPDATA%\slcl` 中的配置缓存

从 0.1.1 覆盖安装即可，配置、账户与已下载的游戏版本不受影响。

## 已知限制

- 仅提供 Windows 构建；其他平台需自行从源码构建（见仓库 README）
- 未做代码签名，SmartScreen 会提示未知发布者
- **前置模组只能识别作者声明过的依赖**：若模组作者没有在 Modrinth / CurseForge 标注前置，
  任何启动器都无法检测（PCL 的作者也确认过这一点）
- 前置只在同一网站内解析，不会跨站按名称猜测
- 中文名来自 MC百科，未收录的模组仍显示英文名
- 整合包安装中途取消，已创建的版本目录不会自动回滚，需在「版本管理」中手动删除
- CurseForge 整合包中个别取不到的文件会被跳过，不影响其余文件安装
- 通过镜像下载**不计入模组作者收益**；若希望支持作者，可在「游戏设置」填写自己的 CurseForge API Key 走官方接口
- 镜像为第三方公益服务，稳定性不受本项目控制，失败时会自动回退官方源

## 数据位置

| 内容 | 位置 |
|---|---|
| 启动器配置 | `%APPDATA%\slcl\config.json` |
| 皮肤缓存 | `%APPDATA%\slcl\skins\` |
| LittleSkin 加密凭据 | `%APPDATA%\slcl\secure\`（`safeStorage` 加密，绑定当前系统账户） |
| 资源名缓存 | `%APPDATA%\slcl\cache\`（中文译名、modId 映射，可安全删除） |
| SLCL 安装的 Java | `%APPDATA%\slcl\java\` |
| 默认游戏目录 | `%APPDATA%\.minecraft` |

Microsoft 访问令牌仅存于内存，不写入磁盘。
