# SLCL v0.1.1

在 0.1.0 的基础上，这一版补齐了下载体验（新增下载管理页）、整合包安装的并发与取消，
并加入 SLATT 团队账号登录、LittleSkin 多角色切换与启动器个性化。

---

## 下载

| 文件 | 说明 |
|---|---|
| `SLCL Setup 0.1.1.exe` | Windows 安装程序（约 110 MB） |
| `SHA256SUMS.txt` | 校验值 |

**系统要求**：Windows 10 / 11（64 位）

> 首次运行时 Windows SmartScreen 可能提示「已保护你的电脑」。这是因为本项目未购买代码签名证书，属于正常现象。
> 点击 **更多信息 → 仍要运行** 即可；你也可以先用 `SHA256SUMS.txt` 校验文件完整性。

## 更新内容

### 新增

- **下载管理页面**：总进度、实时速度、文件总数 / 剩余文件 / 已完成数、当前下载文件、
  已用时长，支持随时取消，并保留最近 20 条历史记录（成功 / 失败分开标记）
- **浮动下载条**：可从任意页面点击标题或「详情」进入下载管理，条上直接显示速度与文件数
- **SLATT 团队账号登录**：slatt.cn 单点登录，登录后可使用团队皮肤库（仅限团队成员账号）
- **LittleSkin 多角色切换**：同一账号下可在多个角色之间切换，无需每次重新输入密码；
  密码用 Electron `safeStorage`（Windows 下为 DPAPI）加密存储，绑定当前系统账户
- **启动器个性化页面**：配色主题、深浅模式、自定义背景图与透明度集中在一处设置
- **MC百科快捷入口**：资源卡片可直接跳转到对应的 mcmod.cn 词条（无匹配时退回搜索页）
- **Fabric API 自动预装**：安装 Fabric 版本时自动装上对应版本的 Fabric API，
  避免「装完启动就崩、提示缺少前置」这一常见问题

### 改进

- **下载并发提升**：库文件 8 → 12，资源对象（assets）12 → 24，缺失文件修复 8 → 12
- **整合包安装改为并发下载**：Modrinth 整合包 8 并发、CurseForge 整合包 6 并发，
  不再一个文件一个文件排队，总耗时明显下降
- **进度真实反映字节数**：整合包安装期间按已下载字节计算总进度，
  而不是只在单个文件完成时才跳一格；子阶段（创建版本 / 解压配置 / 下载模组）
  的进度按比例映射到总进度，**进度条不会再倒退**
- **下载停顿检测**：镜像连接建立后若 20 秒没有任何数据到达，自动中断并回退到下一个源，
  大幅减少「卡在某个百分比一动不动」的情况
- **进度上报节流**：主进程的下载进度合并到约 5 次/秒，界面在大批量下载时保持流畅

### 修复

- 资源下载页「游戏版本」列表的**安装按钮一直显示禁止符号、无法点击**
- 已安装的版本不再重复显示「已安装」标签
- 整合包安装失败时被错误记为「已完成」历史记录，现在会正确标记为失败并显示原因
- 取消下载对整合包安装无效（此前只有版本创建阶段可以取消）
- 下载失败后其余并发任务仍在后台空跑，继续进行无意义的网络请求
- 正版皮肤显示颜色偏移（服务端按 `Accept` 返回有损 AVIF，改为强制请求原始 PNG）
- 报错信息暴露 Electron 内部 IPC 通道名（如 `Error invoking remote method 'slcl:...'`）

## 安装

1. 下载 `SLCL Setup 0.1.1.exe`
2. 双击运行，按向导完成安装
3. 安装位置可选；若只选盘符根目录（如 `D:\`），安装程序会自动装到 `D:\SLCL`，不会把文件散落到根目录
4. 卸载时可选择是否同时删除 `%APPDATA%\slcl` 中的配置缓存

从 0.1.0 升级时可直接覆盖安装，配置与已下载的游戏版本不受影响。

## 已知限制

- 仅提供 Windows 构建；其他平台需自行从源码构建（见仓库 README）
- 未做代码签名，SmartScreen 会提示未知发布者
- 整合包安装中途取消，已创建的版本目录不会自动回滚，需在「版本管理」中手动删除
- CurseForge 整合包中个别取不到的文件会被跳过，不影响其余文件安装
- 通过镜像下载**不计入模组作者收益**；若希望支持作者，可在「游戏设置」填写自己的 CurseForge API Key 走官方接口
- 镜像为第三方公益服务，稳定性不受本项目控制，失败时会自动回退官方源

## 数据位置

| 内容 | 位置 |
|---|---|
| 启动器配置 | `%APPDATA%\slcl\config.json` |
| 皮肤缓存 | `%APPDATA%\slcl\skins\` |
| LittleSkin 加密凭据 | `%APPDATA%\slcl\secure\` |
| SLCL 安装的 Java | `%APPDATA%\slcl\java\` |
| 默认游戏目录 | `%APPDATA%\.minecraft` |

Microsoft 访问令牌仅存于内存，不写入磁盘。
